# SevaConnect Android starter project

## Open and run
1. Extract this ZIP.
2. Android Studio → File → Open → choose the `SevaConnectAndroid` folder containing `settings.gradle.kts`.
3. Wait for Gradle sync. Internet is needed initially to download Gradle plugins and SDK components.
4. If prompted, install Android SDK Platform 35 via SDK Manager.
5. Select an emulator or Android phone, then press Run ▶.

The project is a minimal Kotlin Android app that displays the existing prototype from `app/src/main/assets/index.html` in a WebView. It has no third-party Android library dependencies.

Important: this is a prototype wrapper, not a production marketplace. Real OTP, KYC, location search, backend, booking and payment gateway are not connected. Do not enter real Aadhaar, PAN or bank information.
